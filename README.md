# BlackKiki

**BlackKiki** is an open-source, educational Python project created for learning purposes only.  
It demonstrates how various types of user data (browser profiles, tokens, system information, application artifacts) can be collected and analyzed on Windows systems for research, red-team exercises, digital forensics training, and security awareness education.
